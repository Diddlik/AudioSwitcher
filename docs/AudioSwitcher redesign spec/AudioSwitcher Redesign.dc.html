AudioSwitcher · UI redesign · v1 concept

A quiet utility with one loud button.

The window keeps the existing information architecture: title bar with Save, profile navigation, editor and status bar. Settings becomes a dedicated view next to Quick switch, so the right pane always shows exactly one thing. Selection, editing and activation are separated visually: a tinted row with a bar marks the selected profile, the editor holds the fields, and activation is the only filled accent button in the editor. The last activation is reported as a timestamped event, never as a live “active” state.

Native first
Segoe UI Variable, 4 px control radius, Windows 11 caption buttons. Everything maps to standard Avalonia controls.
One accent, used sparingly
Deep teal marks selection, success and the primary action. Warning and error colors always travel with an icon and text.
Save is visible state
Save turns into the filled primary button and an “Unsaved changes” label appears as soon as anything differs from disk.
01

Main window · 1040 × 700

This window is interactive
  1. Title bar. Extended client area. Refresh devices, the unsaved label and Save sit left of the caption buttons. Save is outlined when clean and filled when dirty.
  2. Profiles. Each row shows name, device summary and its shortcut keycaps. The row sub-line switches to “Activated at 09:41” after an activation and to a warning when a device is missing.
  3. Editor. The profile name is the page title. “Activate now” is the only filled button in the pane. Remove profile is a quiet text button at the end.
  4. Quick switch and Settings live under the list as navigation items, so the list and the editor stay adjacent.
  5. Status bar. Tinted message with icon on the left, update state and version on the right. Messages stay until the next action replaces them.
Try it
Select “Headset” and press Activate now. Select the shortcut field and press keys; Delete clears. Give two profiles the same name or shortcut, then Save. Ctrl + Shift + M simulates a combination registered by another application. Change the language in Settings.
02

Settings, quick switch, empty state

Shown in French, Ukrainian and English to prove longer labels. Settings changes the language immediately; the rest of the window, tray menu and future overlays follow. Quick switch keeps A and B on one row with the swap glyph between them. The empty state appears after the last profile is removed and offers the same add action as the list header.

05

Shortcut capture

The field is a focusable button, not a text box. Focus starts listening; held modifiers preview live; the first valid combination commits and focus returns to the field in rest state. Tab and Shift + Tab are never captured so keyboard users can always leave. Escape cancels listening without changing the value.

Messages persist until the next action replaces them; errors are never auto-dismissed. The message container is an ARIA live region (polite for info/success, assertive for errors). Update failures use the warning style so they don’t compete with configuration errors.
