# AudioSwitcher 1.5.2

- Device availability refreshes automatically when audio devices disconnect or reconnect, including while AudioSwitcher runs in the tray. Saved device assignments are preserved.
- Once an update has downloaded, **Update now** appears in the main window and About dialog. Click it to install the update and restart AudioSwitcher immediately. Updates still install automatically on normal exit.

Download the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.5.2/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive this version through automatic updates.
