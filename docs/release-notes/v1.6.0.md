# AudioSwitcher 1.6.0

- **Tray menu:** activate any profile or the quick switch directly from the tray. The active profile is marked, and profiles with missing devices are disabled.
- **Automatic triggers:** enter program names such as `cs2.exe` in a profile to activate it when one of them starts. After they exit, AudioSwitcher keeps the current profile, restores the previous one, or switches to a selected profile.
- **Keep the active profile:** optionally restore the last activated profile when Windows or another app changes the default devices, for example after plugging in a device.
- **Startup profile:** optionally activate a selected profile every time AudioSwitcher starts.
- **Languages:** German, Spanish, Portuguese (Brazil), and Simplified Chinese join English, French, Italian, Polish, Russian, and Ukrainian.
- The profile list marks only the last activated profile, and toggle switches show localized on/off labels.

Download the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.6.0/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive this version through automatic updates.
