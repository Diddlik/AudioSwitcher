# AudioSwitcher 1.2.0

AudioSwitcher 1.2.0 bringt eine überarbeitete Oberfläche, direkte Shortcut-Erfassung und eine konsistente neue visuelle Identität.

![AudioSwitcher-Hauptansicht](https://raw.githubusercontent.com/Diddlik/AudioSwitcher/main/docs/screenshots/main.png)

## Neu

- Neues AudioSwitcher-Icon in App, Taskleiste, Tray, Installer und Dokumentation
- Shortcuts werden direkt per Tastendruck erfasst statt als Text eingegeben
- `Entf` oder `Backspace` entfernt eine Shortcut-Belegung
- Systemeinstellungen befinden sich in einem separaten Einstellungsmenü
- Die installierte Programmversion ist direkt in der Oberfläche sichtbar
- Zusätzliche Tests für die Tastenerfassung

## Bereits enthalten

- Profile mit je einem Ein- und Ausgabegerät
- Globaler Shortcut pro Profil
- Schnellwechsel zwischen zwei Profilen
- Zuverlässiges Umschalten aller Windows-Audiorollen
- System-Tray, Autostart und automatische Updates

## Installation

Den [Windows-Installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.2.0/Diddlik.AudioSwitcher-win-Setup.exe) herunterladen und starten. Bestehende Installationen erhalten Version 1.2.0 über die integrierte Update-Funktion.

## Einstellungen

Autostart und weitere Systemoptionen sind kompakt in einem eigenen Menü untergebracht.

![AudioSwitcher-Einstellungen](https://raw.githubusercontent.com/Diddlik/AudioSwitcher/main/docs/screenshots/settings.png)

> Der Installer ist noch nicht code-signiert. Windows kann beim ersten Start eine SmartScreen-Warnung anzeigen.
