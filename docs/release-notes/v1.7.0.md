# AudioSwitcher 1.7.0

- **Microphone mute shortcut:** set a shortcut in the Quick switch view to mute or unmute the default microphone. A banner stays at the top of every screen while it is muted, also when it was muted another way, for example with a headset button.
- **Taken shortcuts are visible:** if another application already uses a shortcut, its field turns red with an explanation and the profile list shows **Shortcut in use**. All other shortcuts keep working; previously one taken shortcut disabled every shortcut.
- **Remote control:** the control pipe accepts `{ "command": "mute" }` and reports `microphoneMuted`, so stream-deck plugins can show and toggle the microphone.
- **Tray tooltip:** shows the active profile and whether the microphone is muted.

Download the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.7.0/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive this version through automatic updates.
