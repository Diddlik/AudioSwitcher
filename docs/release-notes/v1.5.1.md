# AudioSwitcher 1.5.1

AudioSwitcher 1.5.1 fixes opening the window after starting with Windows.

## Fixed

- When AudioSwitcher starts with Windows, opening it from the tray now shows the window instead of hiding it again immediately.

## Installation

Download and run the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.5.1/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive version 1.5.1 through the integrated update function.

> The installer is not code signed yet. Windows may display a SmartScreen warning on first launch.
