# AudioSwitcher 1.4.0

## New interface

- A light, teal-accented design with dedicated profile, quick-switch, and settings views.
- Full-width navigation highlights, responsive fields, consistent icons, and clearer hover/focus states.
- Visible unsaved changes and a highlighted Save action.
- Shortcut capture buttons with individual keycaps; Tab leaves capture and Delete/Backspace clears it.
- Activation timestamps describe the last successful action, rather than claiming a continuously monitored active profile.
- Custom title bar extends into the window decoration area to remove the extra top strip.

## About and updates

- New About window with app, .NET, architecture, and Windows version information.
- Links to source code and GitHub releases.
- Current update status and a manual check using the same updater as the startup check.
- An already downloaded update remains pending until exit; repeated checks retain that status.
- Standalone builds explain that automatic updates require an installed copy.
- Credits for 25 restored packages, including transitive and development dependencies, with versions, authors, license references, and NuGet links.

## Languages and validation

- English, Russian, Ukrainian, French, Italian, and Polish, including the About window.
- 31 passing tests, including layout coverage for the main views and About at two sizes in all six languages.
- README includes fresh render images from actual Avalonia controls; earlier German desktop screenshots remain available.

Download `Diddlik.AudioSwitcher-win-Setup.exe` for installation and automatic updates, or use the portable ZIP. Existing profiles remain in `%LocalAppData%\AudioSwitcher\config.json`.

Native desktop capture and an installed update cycle were not exercised during local validation.
