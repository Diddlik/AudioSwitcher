# AudioSwitcher 1.3.0

AudioSwitcher 1.3.0 adds a multilingual interface with English as the default language.

## New

- Choose English, Russian, Ukrainian, French, Italian, or Polish in Settings.
- The selected language applies immediately to the main window, status messages, tray menu, update messages, and profile activation overlay.
- The selected language is stored locally with the existing configuration.

## Installation

Download and run the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.3.0/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive version 1.3.0 through the integrated update function.

> The installer is not code-signed yet. Windows may display a SmartScreen warning on first launch.
