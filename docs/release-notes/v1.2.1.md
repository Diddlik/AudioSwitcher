# AudioSwitcher 1.2.1

AudioSwitcher 1.2.1 confirms successful profile changes without interrupting the active application.

## New

- A short, focus-free overlay appears on every monitor after a profile is activated.
- The overlay remains click-through and works while AudioSwitcher is hidden in the system tray.
- A subtle Windows system sound accompanies successful profile changes.
- Failed profile changes do not show a success notification.

## Installation

Download and run the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.2.1/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive version 1.2.1 through the integrated update function.

> The installer is not code-signed yet. Windows may display a SmartScreen warning on first launch.
