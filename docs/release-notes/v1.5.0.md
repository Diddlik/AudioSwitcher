# AudioSwitcher 1.5.0

## Remote control

- Other programs of the same Windows user can now list, activate, and toggle profiles through the local named pipe `\.\pipe\AudioSwitcher.Control`.
- Each line is one JSON request (`state`, `activate`, `toggle`); every response contains the profiles, their device availability, and the active profile.
- The active profile is the one whose output and input devices are the current Windows defaults, even if they were changed outside AudioSwitcher.
- Activations from the pipe behave like shortcuts, including the notification.
- The [OpenDeckN3 AudioSwitcher plugin](https://github.com/Diddlik/OpenDeckN3/blob/main/docs/PLUGIN_AUDIOSWITCHER.md) uses it to switch profiles from a TreasLin N3 stream deck.

## Validation

- 33 passing tests, including a pipe round trip and rejection of invalid requests.

Download `Diddlik.AudioSwitcher-win-Setup.exe` for installation and automatic updates, or use the portable ZIP. Existing profiles remain in `%LocalAppData%\AudioSwitcher\config.json`.
