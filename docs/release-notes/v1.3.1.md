# AudioSwitcher 1.3.1

AudioSwitcher 1.3.1 fixes live language switching.

## Fixed

- Interface text now changes immediately after selecting another language in Settings.
- The selected language still applies to the tray menu, status messages, update messages, and profile activation overlay.

## Installation

Download and run the [Windows installer](https://github.com/Diddlik/AudioSwitcher/releases/download/v1.3.1/Diddlik.AudioSwitcher-win-Setup.exe). Existing installations receive version 1.3.1 through the integrated update function.

> The installer is not code signed yet. Windows may display a SmartScreen warning on first launch.
